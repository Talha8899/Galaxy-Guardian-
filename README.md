# Galaxy Guardian

**Galaxy Guardian** is a high-octane, arcade-style space shooter built with React and HTML5 Canvas. It combines classic "bullet hell" mechanics with modern visual effects and intelligent enemy behavior.

## 🚀 Core Features
*   **Dynamic Space Combat:** Precision movement and rapid-fire mechanics.
*   **Tactical Depth:** Integrated shield systems with health regeneration and heavy rocket secondary fire.
*   **Wave-Based Scaling:** Difficulty increases dynamically as you clear waves.
*   **Multi-Phase Bosses:** Epic encounters that evolve based on health thresholds.
*   **Parallax Environment:** immersive cosmic backdrop with multiple scrolling layers for depth.

## 🧠 AI & Intelligent Systems
*   **AI Commander:** Manages enemy spawning and strategic movement patterns.
*   **State-Driven Boss AI:** Bosses shift behaviors, attack speed, and visual appearance as they take damage.
*   **Procedural Generation:** Algorithmic creation of planets and starfields for unique play sessions.

## ⚡ Technical Highlights
*   **Pure Code Rendering:** No external image assets; everything is drawn using high-performance Canvas APIs.
*   **Web Audio Synthesis:** Sound effects are synthesized in real-time, avoiding the need for heavy audio files.
*   **React + Canvas Integration:** Seamlessly blends React's declarative UI with a high-performance 60FPS game loop.

## 🎮 Controls
*   **Arrow Keys / WASD:** Move your ship.
*   **Space:** Fire primary lasers.
*   **Shift:** Fire heavy rockets.
*   **Z / Control:** Activate Energy Shield.
